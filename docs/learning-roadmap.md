# Learning roadmap

This is a competency-driven roadmap, not a promise of certification or a fixed-duration course.

## Phase 0 — Baseline
- Review RNCP42463 official activities, competence and evaluation framework.
- Self-assess every competence and identify documentary gaps.
- Establish reproducible VM environment and safe evidence conventions.

## Phase 1 — Support and workstations (BC01)
- PC hardware diagnosis without board-level soldering; Windows installation and recovery.
- User incidents, ticket lifecycle, communication, remote support and collaboration tools.
- Responsible AI assistance, output verification, privacy and escalation.

## Phase 2 — Infrastructure (BC02)
- Cisco Packet Tracer: IPv4, subnetting, VLAN, routing, DNS, DHCP and ACL.
- Linux services and Windows Server/Active Directory, user/group access.
- KVM virtualization, virtual networks, service validation, security baselines.

## Phase 3 — Operations (BC03)
- Bash/PowerShell scripts with tests, AI-assisted review and human verification.
- Backups, restore drills, continuity planning, monitoring, patching and rollback.

## Phase 4 — Exam readiness and VAE review
- Timed hands-on troubleshooting and concise French oral explanation.
- Read short technical documentation in English and answer comprehension questions.
- Compare lab demonstrations with independent professional evidence.
- Decide whether to pursue VAE, training, or CCP blocks with an authorized center.

## Working rule
Every lab includes initial state, task, commands, verification, troubleshooting, sanitized artifacts and lessons learned. Track weaknesses openly.
