# IT Infrastructure Skills

Practical learning, skills assessment and evidence portfolio for **Technicien supérieur systèmes et réseaux (TSSR)** — French **RNCP42463, niveau 5**.

## Objectives
- Build demonstrable skills in IT support, Windows/Linux systems, IP networking, virtualization, security and operational continuity.
- Map each activity to the official TSSR competence framework.
- Prepare for professional assessment and potential **VAE**, without implying that lab work alone validates professional experience.
- Publish sanitized technical case studies for employers and clients.

**Official reference:** https://www.francecompetences.fr/recherche/rncp/42463/ (certification valid 2026-09-01 through 2031-08-31).

## Evidence policy
**Lab evidence** demonstrates tested ability; **professional evidence** documents work actually performed in a professional context. Neither GitHub nor a certificate automatically grants RNCP validation. Never publish customer data, passwords, tokens, private IP schemes, confidential contracts or identifying screenshots. Store sensitive originals outside this public repository.

## Language
Documentation in English, with official French competence names preserved for traceability. French professional vocabulary and exam practice will be added progressively.
